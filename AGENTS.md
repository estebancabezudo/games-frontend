# Instrucciones específicas del frontend de Games

Este repositorio es `games-frontend` y su rama permanente es `games`.

Antes de modificarlo, leer completamente la memoria operativa en
`../backend/docs/frontend-agent-memory.md`. El backend propio vive en `../backend` y
el checkout compartido de Plataforma en `../platform`.

Las memorias, prompts y scripts operativos del producto pertenecen al repositorio
backend. No crear documentación pública durante una tarea de código.
